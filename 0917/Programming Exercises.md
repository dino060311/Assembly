## 1. Integer Expression Calculation

### 영문

Using the AddTwo program from Section 3.2 as a reference, write a program that calculates the following expression, using registers: A = (A + B) − (C + D). Assign integer values to the EAX, EBX, ECX, and EDX registers.

### 해석

Section 3.2의 AddTwo 프로그램을 참고하여, 다음 식을 계산하는 프로그램을 작성하시오: A = (A + B) − (C + D). EAX, EBX, ECX, EDX 레지스터에 정수 값을 할당하시오.

### 풀이

```asm
TITLE Integer Expression Calculation

INCLUDE Irvine32.inc

.code
main PROC
    ; A = (A + B) - (C + D)
    ; EAX = A, EBX = B, ECX = C, EDX = D

    mov eax, 10      ; A = 10
    mov ebx, 5       ; B = 5
    mov ecx, 3       ; C = 3
    mov edx, 2       ; D = 2

    ; (A + B)
    add eax, ebx     ; EAX = 10 + 5 = 15

    ; (C + D)
    mov ebx, ecx     ; EBX = C = 3
    add ebx, edx     ; EBX = 3 + 2 = 5

    ; (A + B) - (C + D)
    sub eax, ebx     ; EAX = 15 - 5 = 10

    call DumpRegs    ; EAX = 10 출력
    exit
main ENDP

END main
```

## 2. Symbolic Integer Constants

### 영문

Write a program that defines symbolic constants for all seven days of the week. Create an array variable that uses the symbols as initializers.

### 해석

요일 7개에 대한 심볼 상수를 정의하는 프로그램을 작성하고, 이 심볼들을 초기값으로 사용하는 배열 변수를 만드시오.

### 풀이

```asm
TITLE Symbolic Integer Constants

INCLUDE Irvine32.inc

MONDAY = 0
TUESDAY = 1
WEDNESDAY = 2
THURSDAY = 3
FRIDAY = 4
SATURDAY = 5
SUNDAY = 6

.data
daysOfWeek BYTE MONDAY, TUESDAY, WEDNESDAY, THURSDAY, FRIDAY, SATURDAY, SUNDAY

.code
main PROC
    mov al, [daysOfWeek]      ; MONDAY (0)
    mov al, [daysOfWeek + 1]  ; TUESDAY (1)
    mov al, [daysOfWeek + 6]  ; SUNDAY (6)

    exit
main ENDP

END main
```

## 4. Symbolic Text Constants

### 영문

Write a program that defines symbolic names for several string literals (characters between quotes). Use each symbolic name in a variable definition.

### 해석

여러 문자열 리터럴에 대한 심볼 이름을 정의하고, 각 심볼을 변수 정의에 사용하시오.

### 풀이

```asm
TITLE Symbolic Text Constants

INCLUDE Irvine32.inc

red = "Red"
blue = "Blue"
green = "Green"
yellow = "Yellow"

.data
colorRed    BYTE red, 0
colorBlue   BYTE blue, 0
colorGreen  BYTE green, 0
colorYellow BYTE yellow, 0

.code
main PROC
    lea eax, colorRed      ; Red 주소
    lea eax, colorBlue     ; Blue 주소
    lea eax, colorGreen    ; Green 주소
    lea eax, colorYellow   ; Yellow 주소

    exit
main ENDP

END main
```

## 5. Listing File for AddTwoSum

### 영문

Generate a listing file for the AddTwoSum program and write a description of the machine code bytes generated for each instruction. You might have to guess at some of the meanings of the byte values.

### 해석

AddTwoSum 프로그램의 리스팅 파일을 생성하고, 각 명령어에 대해 생성된 기계어 바이트를 설명하시오. 바이트값의 의미를 추측해야 할 수도 있습니다.

### 풀이 및 기계어 분석

```asm
TITLE AddTwoSum

INCLUDE Irvine32.inc

.data
sum DWORD 0

.code
main PROC
    mov eax, 5        ; 기계어: B8 05 00 00 00
    add eax, 6        ; 기계어: 83 C0 06
    mov sum, eax      ; 기계어: A3 [메모리주소]

    call DumpRegs
    exit
main ENDP

END main
```

### 기계어 분석표

| 명령어         | 기계어           | 분석                                     |
| -------------- | ---------------- | ---------------------------------------- |
| `mov eax, 5`   | `B8 05 00 00 00` | B8=MOV 명령, 05 00 00 00=5 (리틀엔디안)  |
| `add eax, 6`   | `83 C0 06`       | 83=ADD 명령, C0=ModR/M (EAX), 06=6       |
| `mov sum, eax` | `A3 [addr]`      | A3=MOV 명령, [addr]=메모리 주소 (32비트) |

## 6. AddVariables Program (64-bit 수정)

### 영문

Modify the AddVariables program so it uses 64-bit variables. Describe the syntax errors generated by the assembler and what steps you took to resolve the errors.

### 해석

AddVariables 프로그램을 수정하여 64비트 변수를 사용하도록 하시오. 어셈블러에서 발생하는 구문 오류를 설명하고, 오류를 해결하기 위해 취한 조치를 설명하시오.

### 원본 (32비트)

```asm
TITLE AddVariables (32-bit)

INCLUDE Irvine32.inc

.data
val1 DWORD 10000h
val2 DWORD 20000h
val3 DWORD 0

.code
main PROC
    mov eax, val1
    add eax, val2
    mov val3, eax

    call DumpRegs
    exit
main ENDP

END main
```

### 수정본 (64비트)

```asm
TITLE AddVariables (64-bit)

INCLUDE Irvine64.inc

.data
val1 QWORD 10000h
val2 QWORD 20000h
val3 QWORD 0

.code
main PROC
    mov rax, val1      ; 64비트 레지스터 사용
    add rax, val2      ; 64비트 덧셈
    mov val3, rax      ; 64비트 저장

    call DumpRegs
    exit
main ENDP

END main
```

### 발생한 오류 및 해결방법

| 오류                       | 원인                                    | 해결방법              |
| -------------------------- | --------------------------------------- | --------------------- |
| "Irvine32.inc 호환 불가"   | 32비트 라이브러리 사용                  | Irvine64.inc로 변경   |
| "mov val1, eax 불가능"     | 32비트 레지스터로 64비트 변수 접근 불가 | `mov rax, val1` 사용  |
| "val3 메모리에서 메모리로" | x86 메모리-메모리 연산 불가             | 레지스터 경유 (`rax`) |
| "DWORD vs QWORD 불일치"    | 타입 불일치                             | DWORD → QWORD로 변경  |
